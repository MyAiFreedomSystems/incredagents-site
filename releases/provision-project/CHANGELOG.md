# Changelog

All notable changes to provision-project are documented here. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-08-14

### Added
- Initial public release: provision an agent-ready project workspace with
  governance files, canonical directory skeleton, session ledger,
  platform-specific instruction files (Hermes, Claude Code, Codex, Cursor,
  OpenCode), optional agent auto-provisioning from a YAML block, and a
  self-verification step.
- Scrubbed of all personal names, paths, and machine details; internal brand
  footer replaced with the public program link.
